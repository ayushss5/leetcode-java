## Problem-Solving Approach

For every problem, I aim to understand four things:

1. **Trap** — The tricky part of the problem.
2. **Approach** — The algorithmic approach used.
3. **Idea** — The underlying intuition.
4. **Mistake** — Common pitfalls and implementation errors.

My focus is on understanding why an algorithm works rather than memorising solutions.
